Coolify Extension

This is the Coolify extension for Chatons. It allows you to interact with your Coolify instance directly from Chatons.

Note: This extension is API-only and doesn't provide a graphical interface. All interactions happen through LLM tools and the Chatons interface.

Features

  • List and manage applications
  • View and validate servers
  • Manage databases and services
  • Trigger deployments
  • Monitor resources and health

Setup

To use this extension, configure your Coolify credentials in the extension settings:

  1. Enter your Coolify instance URL
  2. Generate and enter your API token from Coolify dashboard
  3. Credentials are saved securely in Chatons local storage
